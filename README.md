# Hack Midwest Reimagined

A responsive Hack Midwest event website with a blue visual theme, horizontal challenge and award cards, schedule, FAQ, rules, and original sponsor logos.

**Website:** https://ahmadbukhari8966.github.io/hack-midwest-reimagined/

## Website source

`website-source.zip` contains the complete editable React/Vinext project, original assets, and build instructions. Download and unzip it to work on the website locally.

The GitHub Actions workflow unpacks the source, installs its locked dependencies, builds the static website for this repository's address, and publishes it to GitHub Pages. The publishing workflow can read repository contents and deploy Pages; it cannot write to this repository.

To publish updates, replace `website-source.zip` with the updated project archive and commit it to `main`. To republish the current version, open **Actions → Publish website → Run workflow**.

Event information and company logos originate from [Hack Midwest](https://hackmidwest.com/). Company names and logos remain the property of their respective owners.
